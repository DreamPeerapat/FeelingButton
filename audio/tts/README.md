# audio/tts/ — bundled offline voice (do not need to touch)

These `*.mp3` files ship with the project so the board **always makes sound**,
even with no internet and in browsers without the Speech Synthesis API. They are
generated by the open-source **eSpeak NG** engine, so the voice is robotic —
clear enough to understand, but not natural.

They are the app's **step 2** fallback. To get a natural voice, add a file at
`audio/<key>.mp3` (a real human recording, or an Amazon Polly clip from
`scripts/generate_audio.py`) — that takes priority over the file here.

Regenerate these with:

```
apt-get install -y espeak-ng
pip install lameenc
python scripts/generate_offline_tts.py
```
